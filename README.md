# Trade-Agreement-V2
War.app mod featuring trade agreements, markets, investments, taxation, ideology, diplomacy, and smart AI.


## V3 Strategic Resources

V3 adds territory-based strategic resources (Oil, Gas, Uranium, Iron, Food, Rare Earths, with optional Coal, Copper, and Lithium), visible War.app structures, recurring resource trade contracts, resource shortages that affect Commerce/mobilization, and player-funded facility upgrades. Resource placement can use realistic 2026 slot profiles or randomized territory placement.

## V3 United Nations / Security Council

V3 adds an optional host-controlled United Nations system with configurable permanent and rotating Security Council seats, permanent-member vetoes, AI voting, rotating membership, and five initial resolution types: sanctions, embargoes, aid, condemnations, and ceasefires.

## Resource Map Display

All strategic resources use one shared Resource Hub structure icon on the map. The number beside the icon is the combined facility/deposit level on that territory. The host may disable Resource Hub map icons globally while leaving the resource economy active. Players may independently hide the Resources menu tab, but War.app native territory structures cannot currently be hidden for only one player.
